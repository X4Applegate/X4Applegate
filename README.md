### 🧰 What I'm building

**[CaddyUI](https://github.com/X4Applegate/caddyui)** — a self-hosted web UI for the [Caddy](https://caddyserver.com/) web server. Manage proxy hosts, redirections, TLS certificates and advanced routes across one server or a whole fleet, without touching a config file. Written in Go, ships as a multi-arch `scratch` image, and runs as a non-root user.

- Apache-2.0 · 35,000+ Docker pulls · 70+ releases
- Managed DNS and DNS-01 wildcard certificates for Cloudflare, Route 53, Hetzner, Porkbun, Gandi and more
- Fleet sync, visitor analytics with per-path and per-visitor drill-down, CrowdSec and Prometheus integration
- OIDC/SSO, TOTP, role-based access control, per-host rate limiting and Basic Auth
- 99 / 100 / 100 / 100 on Lighthouse — [case study](https://richardapplegate.io/case-studies/caddy-ui/)

**[status-server](https://github.com/X4Applegate/status-server)** — a multi-tenant server and network status monitoring platform. Separate branded dashboards for different teams or clients, each with their own login and server visibility, from a single deployment.
